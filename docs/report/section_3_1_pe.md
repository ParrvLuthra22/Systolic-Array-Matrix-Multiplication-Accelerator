# Section 3.1: Processing Element

**Author:** Raghav

**Files:** `rtl/pe.v`, `tb/tb_pe.v`

## Purpose

The processing element (PE) performs one signed multiply-accumulate operation for a single output matrix element. It also registers each input and forwards it to the next PE in the row or column.

## Interface

| Port | Direction | Width | Meaning |
|---|---|---:|---|
| `clk` | Input | 1 | Rising-edge clock |
| `rst` | Input | 1 | Synchronous, active-high reset |
| `clear` | Input | 1 | Clears the accumulator, with priority over `en` |
| `en` | Input | 1 | Enables accumulation |
| `a_in`, `b_in` | Input | 8 each | Signed operands |
| `a_out`, `b_out` | Output | 8 each | Registered copies of the operands |
| `acc` | Output | 32 | Signed running sum |

## Operation

At each rising clock edge, reset sets both pass-through registers and the accumulator to zero. Otherwise, the PE captures `a_in` and `b_in` every cycle so data continues through the array even when accumulation is disabled. `clear` sets `acc` to zero. When `clear` is low and `en` is high, the PE adds the signed product `a_in * b_in` to `acc`. When both controls are low, the accumulator holds its value.

## Verification

`tb/tb_pe.v` checks synchronous reset, three positive products summing to 68, mixed-sign products, the three directed extreme accumulations (64,516, 65,536, and −65,024), clear priority, accumulator hold when `en=0`, and registered pass-through behavior. The bench prints `PE TESTS PASSED` only when every check succeeds and writes `wave_pe.vcd` for waveform inspection.

Verification command: `make pe`. Icarus Verilog 13.0 reports `PE TESTS PASSED (27 checks)`. The project suite also reports `ALL 10 TESTS PASSED` for the integrated systolic design, with `cycle_count = 11` for each case. The sequential baseline reports `ALL 10 TESTS PASSED` with `cycle_count = 64`.
